问题背景 01

coding agent 走向
自改进闭环

  1. 1987

    自改进 AI 与元学习

    AI 借助元学习反复改写自身，并在迭代中提升能力。Schmidhuber, 1987。

  2. 2003 至 2007

    哥德尔机器

    在取得可证明的收益时进行严格的自指修改。Schmidhuber, 2003，Schmidhuber, 2007。

  3. 2024 至 2026

    基于 LLM 的 coding agent

    LLM 让 coding agent 能够在真实任务中完成评估、修改与再评估。Yang et al., 2024，Hu et al., 2024，Gao et al., 2026。

  4. 2026

    经验性 RSI 闭环

    coding agent 编辑自身源码，并且只在基准性能提升时保留改动，以经验评估近似哥德尔式准则。

经验性 RSI 的基本流程

任务评估　失败诊断　自主修改　回归评估

coding agent 根据任务表现与失败轨迹定位问题，并修改自身源代码，包括提示、工具、控制逻辑与辅助例程。

每次修改都在留出任务上重新评估，以判断能力是否真正提升。

性能提升的版本进入档案库，其余版本被淘汰，随后开始下一轮迭代。

HGM Liu et al., 2026

在固定预算下把档案库作为搜索树，并依据分支后代表现分配 \(\varphi\) 评估与 \(\Phi\) 扩展。

现有自主修改以单个 coding agent 的单次失败轨迹为主要证据。 MGM 将档案库中的跨任务与跨谱系轨迹纳入修改环节。

核心问题 03

档案库轨迹
驱动自主修改

档案库提供搜索信号

  • 谱系树存储所有生成的 coding agent 及其评估轨迹。
  • \(\pi\) 采样分配评估与扩展预算。
  • 根据分支后验确定节点的探索优先级。

比较轨迹提供修改信号

  • \(\Phi\) 自主修改汇总跨任务失败模式。
  • 跨任务对比区分重复缺陷与偶然失误。
  • 其他谱系的成功轨迹支持能力迁移。
MGM 核心机制 把已有轨迹转化为 \(\Phi\) 的比较证据，无需新增任务评估或 token 消耗。

基线骨架 04

MGM 重构 HGM
扩展证据

档案库把 coding agent 组织为可搜索谱系

coding agent \(a\in\mathcal{A}\) 的提示、工具与控制逻辑构成基因型，任务轨迹 \(\varphi(a,\tau)\) 与结果 \(r(a,\tau)\) 构成可观测表型。

节点记录已评估任务 \(S_i\) 与失败集 \(F_i\)，分支 \(C_t(a)\) 聚合后代统计。

\[U(a)=\mathbb{E}_{\tau\sim\mathcal{D}}[r(a,\tau)]\]
\[n_\mathrm{s}(a_i)=|S_i|-|F_i|,\qquad n_\mathrm{f}(a_i)=|F_i|\]

\(\pi\) 策略分配评估与扩展预算

HGM 对节点或分支成功率维护 Beta 后验，并据此选择下一次 \(\varphi\) 评估或 \(\Phi\) 扩展。

自主修改可写为 \(a' \leftarrow \Phi(a,E)\)。MGM 保留 \(\pi\) 策略，仅改变证据 \(E\) 的构造方式。

\[\pi_a\sim\mathrm{Beta}\!\left(\kappa(1+n_\mathrm{s}(a)),\kappa(1+n_\mathrm{f}(a))\right)\]
\[a' \leftarrow \Phi(a,E)\]
继承与改写 MGM 继承 HGM 的档案库与 \(\pi\) 采样，并将单轨迹证据升级为跨任务与跨谱系比较证据。

方法总览 05

MGM 比较
演化闭环

孟德尔-哥德尔机 MGM。 基于跨任务与跨谱系比较证据，通过受控遗传组织自主修改。 每轮以 π 采样决定执行 φ 评估或 Φ 扩展。 CM、RM 与 CH 分别使用单轨迹、跨任务与跨谱系证据。

MGM 方法 06

比较轨迹
定位可修复缺陷

同一基因型跨任务比较

跨任务评估形成 反应规范，描述同一基因型在不同环境中的表现。

对比反复出现的失败模式，可以区分基因型层面缺陷与任务偶然失误。

不同谱系同任务比较

多个 coding agent 尝试同一任务时，轨迹揭示可迁移的行为特征。

对比证据指出可迁移的能力及其来源，减少重复探索。

设计原则 受孟德尔遗传学的受控比较启发，MGM 将证据范围明确映射为 CM、RM 与 CH 三种演化算子。

MGM 方法 07

三种算子
组织比较证据

CM 克隆突变

作为基线算子，基于单一失败轨迹执行传统的自主修改。

\[E_{\mathrm{CM}}(i,\tau)=\{(\varphi(a_i,\tau),r(a_i,\tau))\}\]

RM 反应规范突变

比较同一基因型在多个任务上的表型，从反复出现的失败模式中区分基因型层面缺陷与任务偶然失误。

\[|S_i| \ge m_{\mathrm{RM}}\]
\[E_{\mathrm{RM}}=\big\{(\varphi(a_i,\tau_t),r(a_i,\tau_t)),(\varphi(a_i,\tau_r),r(a_i,\tau_r))\big\}\]

CH 跨谱系杂交

比较不同谱系在同一任务上的表现，识别可迁移能力并减少重复探索。

\[\exists j\ne i,\ \tau_t\in S_i\cap S_j:\ \neg\big(r(a_i,\tau_t)=1\land r(a_j,\tau_t)=1\big)\]
\[E_{\mathrm{CH}}=\big\{(\varphi(a_t,\tau_t),r(a_t,\tau_t)),(\varphi(a_r,\tau_t),r(a_r,\tau_t))\big\}\]
统一接口 三种算子均执行 \(a' \leftarrow \Phi_\sigma(a_t,E_\sigma)\)，差异来自目标 coding agent 与比较证据的选择。

MGM 方法 08

轨迹复用
实现预算内扩展

失败任务池提高评估信息量

MGM 维护全局失败任务池，汇总各 coding agent 已发现的失败任务，并复用现有 \(\varphi\) 评估结果。

为 coding agent \(i\) 采样待评估任务时，提高档案库中已失败任务的权重。

\[\mathcal{P}_t=\bigcup_{i\in\mathcal{V}_t} F_i\]
\[w_i(\tau)= \begin{cases} \beta_{\mathrm{fail}}, & \tau\in\mathcal{P}_t,\\ 1, & \tau\notin\mathcal{P}_t, \end{cases} \qquad \tau\notin S_i\]

证据可用性决定扩展算子

当 \(\pi\) 为父代 \(a_i\) 选择 \(\Phi\) 扩展时，MGM 根据档案库证据构造可用算子集 \(\Omega_i\subseteq\{\Phi_{\mathrm{CM}},\Phi_{\mathrm{RM}},\Phi_{\mathrm{CH}}\}\)，再从中采样。

\[\Pr(\sigma\mid i)= \frac{\lambda_\sigma}{\sum_{\sigma'\in\Omega_i}\lambda_{\sigma'}}, \qquad \sigma\in\Omega_i\]
\[a' \leftarrow \Phi_\sigma(a_t,E_\sigma)\]
预算边界 HGM 与 MGM 使用相同 \(\pi\) 采样骨架，MGM 通过 \(\Phi\) 扩展组织并执行比较证据。

理论解释 14

加性景观
刻画位点修复

二元基因型与汉明距离

每个 coding agent 携带基因型 \(\mathbf{g}\in\{0,1\}^{L}\)，理想最优基因型 \(\mathbf{g}^{*}=\mathbf{1}\) 表示最优程序。系统不直接观测基因型，而用汉明距离描述它与最优解之间的差距。

\[d(\mathbf{g})=\sum_{\ell=1}^{L}\mathbf{1}\!\left[g_{\ell}\neq g^{*}_{\ell}\right]\]
\[M(a)=\{\ell\in[L]: g_{\ell}(a)\neq g^{*}_{\ell}\}\]

任务考察与成功概率

各任务 \(\tau\) 考察子集 \(R_{\tau}\subseteq[L]\)，\(|R_{\tau}|=k\)。所需位点全部正确时，coding agent 解决任务 \(\tau\)。

\[r(a,\tau)=1 \Leftrightarrow R_{\tau}\cap M(a)=\varnothing\]
\[P(r{=}1\mid d)=\Bigl(\tfrac{L-d}{L}\Bigr)^{k}\]
替身模型 基因型代表框架能力，任务检验能力子集，编辑距离刻画 coding agent 与理想程序的距离。

理论解释 15

比较证据
提高有效修复概率

有效修复概率

算子 \(\sigma\) 用证据 \(E\) 形成候选位点集 \(C_{\sigma}(E)\)，命中真错配位点时以概率 \(s\) 修复。

\[p_{f}^{\sigma}=s\cdot\Pr_{\ell\sim C_{\sigma}(E)}[\ell\in M(a)]\]

\(\Phi_{\mathrm{CM}}\) 用 \(C_{\mathrm{CM}}=R_{\tau_t}\)。

\(\Phi_{\mathrm{RM}}\) 将候选集合缩小为 \(C_{\mathrm{RM}}=R_{\tau_t}\cap R_{\tau_r}\)，\(\Phi_{\mathrm{CH}}\) 则利用参考轨迹过滤 \(R_{\tau}\)。

命题 1 蒙特卡洛设定

在有效比较证据下，\(\Phi_{\mathrm{RM}}\) 与 \(\Phi_{\mathrm{CH}}\) 的有效修复概率严格高于 \(\Phi_{\mathrm{CM}}\)。

\[p_{f}^{\mathrm{RM}}>p_{f}^{\mathrm{CM}},\qquad p_{f}^{\mathrm{CH}}>p_{f}^{\mathrm{CM}}\]
\[\rho=\frac{p_{f}^{\mathrm{RM}}}{p_{f}^{\mathrm{CM}}}=\frac{p_{f}^{\mathrm{CH}}}{p_{f}^{\mathrm{CM}}}\]
诊断收益 等成本设定隔离比较证据的贡献，\(\rho>1\) 对应有效诊断收益。
